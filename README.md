# 🐍 Snake Game (Python + Pygame)

A modern twist on the classic Snake Game — built with Python and Pygame, featuring cool graphics, sounds, power-ups, and high score tracking.

## 🎮 Features

- 🐍 Snake movement & collision detection
- 🍎 Food with sound effects when eaten
- 💥 Crash sound + Game Over screen
- 🎯 Score & High Score tracking (auto-saved)
- ⚡ Power-Ups: Slow motion & Double Points
- 🎨 Themed skins with custom assets
- 🧭 Main menu screen with start prompt

## 🧱 Requirements

- Python 3.x
- `pygame` (install with pip)

```bash
pip install pygame
```

## 🚀 How to Run

```bash
python main.py
```
